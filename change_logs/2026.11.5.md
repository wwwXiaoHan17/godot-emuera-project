# 2026-11-05 · 面板、地图与字体补字

承接 [2026.11.4 的计划](2026.11.4.md)：第 1 件事（Emuera HTML 界面在 Godot 里复刻）和
第 2 件事（ASCII 地图）各做了一个能跑的版本，另外补了字体缺字，并把面板和地图接进了第 1 天。

## 为什么做

11.4 的两件事都还停在「研究 + 测试场景」：EraFlet 只是 `scenes/panel_test.tscn` 里手摆的
PanelContainer 加手写的 `custom_minimum_size`，放回 VBox 里会把后面 Label 的行距顶乱；
ASCII 地图也只有一张 9×6 的 ■ 示意，没有从 Emuera 那边搬真实数据来验证。另外，地图里用到的
`∬`、`卍` 和文案里的 `·` 在 GEMono SC 里都没有字形，实测缺字的宽度并不固定（12px、8px、
16px 都有），原样使用会把那一行压窄、整张图错位。

## 方案

地图这边，翻 eraTW 的 ERB 看到地图是一整行 HTML 字符串里夹 `<button value='地点编号'>`，
数字用全角来保证和字符画同宽。Godot 里对应做成「一行按数字切段」：非数字段用 RichTextLabel
逐字上色（宽度按主题字体逐字实测后固定），数字段用真 Button（宽度 = 字数 × 8px，正好是字符画
的半角格），整行再用间距 0 的 HBox 拼起来；行高 22px、行距 26px，和普通文字行完全对齐。
数据从 eraTW 的 `COLOREDFIELD.ERB` 抄了 32 行字符画和每格颜色（去掉零宽空格），放在
`content/maps/` 下；引擎侧新增 `Era.print_map()` 和 `engine/rows/ascii_map_row`。

面板这边定下来的是：面板混在文字流里、跟着历史一起滚；坐标和大小由内容脚本手写；每个面板
自己声明占几行，整块高度取最大值（行数 × 26 − 4），保证后面的文字仍落在同一套行距上；面板
里的内容用命令拼，默认竖排，横排时插 `begin_hbox`；面板是死框，内容超出就裁掉并在开发时
`push_warning`；按钮照常接入 `Era.input()`，输入结束后整块变灰；原地更新暂时不做，需要就
重新打印一块。命令是 `begin_panels` / `begin_panel` / `end_panel` / `begin_hbox` /
`end_hbox` / `end_panels`，实现在 `engine/rows/panel_block`。

字体这边，把 `∬`（U+222C）、`卍`（U+534D）、`·`（U+00B7）补进了字符集。EraMono 有这
三个字形，MS Gothic 的度量是前两个全角、`·` 半角；重建后字符集 8733、实有字形 8427、缺字
仍是 310 个，advance 修正从 300 处变成 301 处。主题重新内嵌了一次（`assets/themes/era_theme.tres`），
地图数据也换回了原字符。

最后是真实内容。`content/events/day_start.gd` 改成两块面板：左边状态（第 N 天、名字年龄、
体力精力、好感、天赋），右边菜单（6 个按钮，最后一个是「看地图」，编号 5）。「看地图」进入
新事件 `content/events/world_map.gd`，点地图上的数字会返回地点编号，按键后回到第 1 天。
测试也跟着改了：`check_day_start` 改成按面板块判断是否到站，并加了地图链路；
`check_content_fixes`、`check_talent_select` 里原来按 13 行判断第 1 天的逻辑一起换掉。

## 结果

- 全量 **23/23** 个 `check_*.tscn` 通过（Godot 4.8-dev7 headless）；
- F5 主链路（标题 → 创建 → 天赋 → 第 1 天 → 看地图 → 角色面板 → 动作后重画）在
  `check_day_start` 里全链路跑过，`main.tscn` 冒烟无报错；
- 截图：`experiment/shots/daystart_panels_screen.png`、
  `world_map_screen.png`、`panels_era_flet_prototype.png`；
- `tools/font/` 的 charset、report、README 同步，`tests/check_font_contract` 加了这三个字的断言。

## 遗留

- 地图数据怎么来还没定：先手写常量、从 2D 数据生成、还是照搬 eraTW 的生成逻辑。
- 面板只做了「重新打印」这一种更新方式；原地更新、toggle 选择项、hbox 里还能放什么、右侧
  面板怎么定位、边框和内边距可调，都还没做。
- 字体还剩 310 个罕符号缺字，缺字宽度不固定（12px、8px、16px 都有），以后字符画再遇到
  它们还会错位，需要时再补。
- 工作区改动这次没有提交。
