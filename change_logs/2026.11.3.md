# 2026-11-03 · 字体改造：GEMono SC（0.0.1）

## 为什么做

检查 UI 时发现：使用 MS Gothic.ttf 作为主题字体时，一部分 Label 和 Button 的 `size.y`
会出现像素级不一致——平常行高 17px，一旦文本里出现「查」这类字，按钮就变成 22px，
后面的布局也跟着错位。

## 原因

MS Gothic 缺少部分中文字形（GB2312 的 6763 个常用汉字只覆盖了 66.4%，共 4488 个，
「查」「测」「说」都不在字体里），缺字会退回 Godot 的系统回退字体。本项目还没有实现
Emuera 那样的固定行高/尺寸处理，而 Godot 的行高取「同一行里所有字体 ascent / descent
的最大值」——回退字体的行高把整行撑高，于是高度再也调不齐；另写一个 Button 子类
也只会让问题更复杂。

## 方案

排查一圈后发现 Ele（era-electron）默认使用的是 **EraMono SC.ttf**（等距时代黑体，
由开源的 Sarasa Gothic 改造而来，SIL OFL 授权）。在我早期的 GDEmuera 中，也曾基于
Sarasa Gothic 改造过字体，但效果不理想。这次把那次「失败品」的经验复用起来：
以 EraMono SC 为字形基底，叠加 MS Gothic 的度量语义，做出项目定制字体 **GEMono SC.ttf**。

具体做法：

- 字形全部来自 EraMono SC（GB2312 全覆盖）；MS Gothic 只作为 advance 语义基准，
  不复制其字形轮廓（微软字体不可随仓库分发）；
- 按 MS Gothic 语义对齐 300 处半/全角宽度，让 `┏━┓`、`▰▱`、`→←↑↓` 这类字符画的
  格子口径与 Emuera 保持一致；
- 丢弃 GPOS/GSUB，保证没有 kerning、advance 严格等宽：@16px 时半角 8px、全角 16px；
- 关闭系统回退，`.notdef` 改为全角——缺字只显示方块，不再改变行高；
- 字体以「内嵌 FontFile」形式写进 `assets/themes/normal_theme.tres`；
- 新增 `tests/check_font_contract` 守卫度量契约，`engine/font_guard.gd` 在运行期报缺字；
- 构建与替换流程全部脚本化，见 `tools/font/README.md`。

## 结果

- 任意中文文本行高稳定为 **22px**（GEMono SC 的原生行高，本次不做固定行高），
  「查」不再撑高按钮；
- 全量 **21/21** 校验场景通过（Godot 4.8-dev7 headless）；
- 对应提交：`a57a7ca`。

## 遗留

GEMono SC.ttf 目前是 **0.0.1** 版本，后续发现问题会继续修改。另有 310 个极罕见符号
（占星、国际象棋、杂项 dingbat 等）没有覆盖，显示为方块并会 `push_warning`，
不影响正常中文文本。
